# grid-ruler

网页半透明网格标尺：一键开关，快速目测字体大小与大致间距（版式人肉参考工具）。

## 网格规格（vivi 设计令牌版）

网格贴紧浏览器边缘，数字从 0 起，透明度分层保证 8/32/128 一眼可分：

| 颜色 | 间距 | 不透明度 | 作用 |
|------|------|---------|------|
| 灰 `#9AA39E` | 8px | 30% | 最小粒度 |
| 绿 `#74A63F` | 32px | 70% | 中档 |
| 深绿 `#3E571C` | 128px | 100% | 最大档 |

- **顶部 + 左侧像素标尺**：每 128px 标数字（深绿，12px 字重 400，无背景垫底），横竖都能数
- **网格开关小面板（可拖动）**：124×30 圆角（8px）小卡片 = 「网格」标签 + 8px/32px/128px 色块（数字带 px 单位悬浮在色块上），色块与网格线同款透明度（所见即所得）；点色块开关对应层，关掉的层变灰、线消失
- **默认贴右下角，距右/下各 32px**；整张卡片就是拖动把手（像输入法候选窗一样按住拖走），拖动跟手、松手记住位置（同一标签页刷新后仍在原处，关掉整个网格再打开也保留）
- **拖动不会误触发开关**：按下后位移小于 3px 算点击，超过才算拖动；拖动结束不会顺带切换它起点下面的那一层
- **位置钳制在视口内**：拖到屏幕外会被限制住，窗口缩小后也会被拉回可见范围，永远不会滑出屏幕
- **总开关不在面板里**：开/关整个网格走工具栏图标 / Alt+Shift+G
- 覆盖层不拦截鼠标点击（只有那张小面板可交互）

## 使用

### 方式一：Chrome 扩展

1. `chrome://extensions` → 开启「开发者模式」→「加载已解压」→ 选本目录
2. 点工具栏图标，或按 `Alt+Shift+G` 开/关网格
3. 网格打开后，右下角（距边 32px）出现 124×30 小面板：点 8/32/128 色块独立开关该层；按住面板拖到任意位置；关掉整个网格走工具栏 / 快捷键（面板里没有总开关）
4. 改动代码后：扩展页「重新加载」+ 刷新目标页面才生效

### 方式二：书签（Bookmarklet）

零安装零权限。把 `javascript:` 开头的 URL 粘到书签「网址」栏，点一下开、再点关。
现成 URL 在 `bookmarklet.txt`。改源码后用 bun 重新生成：
`bun build content.js --minify` 后加 `javascript:` 前缀覆盖写入 `bookmarklet.txt`。

## 结构

| 文件 | 作用 |
|------|------|
| `content.js` | 单一真相源。扩展 content script 与书签共用，靠运行时上下文检测分叉（有 `chrome.runtime` → 注册消息监听；否则立即执行开关）。含每层 8/32/128 状态 + 可拖动小面板（指针捕获拖动、3px 点击阈值、位置存 sessionStorage） |
| `background.js` | 扩展 service worker。图标 / 快捷键 → 发消息；旧页面未刷新时现场注入兜底 |
| `manifest.json` | MV3 清单 |
| `bookmarklet.txt` | 书签版现成 URL（bun 压缩 content.js 生成，UTF-8 无 BOM） |
| `test/` | 验证。见下表 |

`test/` 里的脚本（都需要本机 Python + Playwright + Pillow）：

| 脚本 | 验证内容 |
|------|---------|
| `verify_final.py` | 主验证：网格线颜色/透明度、标尺数字、面板几何（124×30、圆角 8px、距右下各 32px）、层开关、真实鼠标点击 vs 拖动、拖动落点/持久化/视口钳制/窗口缩小。通过输出「ALL REQUIREMENTS PASS」 |
| `check_corners.py` | 圆角像素级验证：面板渲染到透明背景，按 alpha 轮廓逐行量圆角曲线，与半径 8px 的圆弧比对（方角会是平的） |
| `check_bookmarklet.py` | 书签路径冒烟：粘贴 `bookmarklet.txt` 能开面板（几何一致）、能拖动、能点色块、再点一次关闭 |
| `shots.py` | 生成面板特写图（4 倍放大），供人工眼看配色与圆角 |

## 边界

- 扩展根目录禁止任何 `_` 开头的一级文件/目录（如 `_runtime`）——Chrome 保留前缀，整个扩展拒载
- 本机 Chrome 有扩展加载策略，命令行 `--load-extension` 加载不了；走 UI「加载已解压」不受此限
