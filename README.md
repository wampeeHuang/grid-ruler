# grid-ruler

网页半透明网格标尺：一键开关，快速目测字体大小与大致间距（版式人肉参考工具）。

## 网格规格

| 颜色 | 间距 | 作用 |
|------|------|------|
| 蓝色细线 | 8px | 最小粒度 |
| 蓝色粗线 | 32px | 中档 |
| 洋红粗线 | 128px | 最大档 |

- **顶部 + 左侧像素标尺**：每 128px 标数字，横竖都能数
- **左下角图例**：色块直接标注 8px / 32px / 128px，最小格多少一格不用猜
- 覆盖层不拦截鼠标点击

## 使用

### 方式一：Chrome 扩展

1. `chrome://extensions` → 开启「开发者模式」→「加载已解压」→ 选本目录
2. 点工具栏图标，或按 `Alt+Shift+G` 开/关网格
3. 改动代码后：扩展页「重新加载」+ 刷新目标页面才生效

### 方式二：书签（Bookmarklet）

零安装零权限。把 `javascript:` 开头的 URL 粘到书签「网址」栏，点一下开、再点关。
URL 由 `content.js` 生成：压缩换行 + 加 `javascript:` 前缀，改源码后需重新生成。

## 结构

| 文件 | 作用 |
|------|------|
| `content.js` | 单一真相源。扩展 content script 与书签共用，靠运行时上下文检测分叉（有 `chrome.runtime` → 注册消息监听；否则立即执行开关） |
| `background.js` | 扩展 service worker。图标 / 快捷键 → 发消息；旧页面未刷新时现场注入兜底 |
| `manifest.json` | MV3 清单 |

## 边界

- 扩展根目录禁止任何 `_` 开头的一级文件/目录（如 `_runtime`）——Chrome 保留前缀，整个扩展拒载
- 本机 Chrome 有扩展加载策略，命令行 `--load-extension` 加载不了；走 UI「加载已解压」不受此限
