# 网格标尺 · 书签安装与测试（给不写代码的人）

不需要装扩展、不需要开发者模式、不需要 GitHub。就三步。

---

## 第 1 步：把书签代码复制到剪贴板

打开这个文件：`D:\workspace\grid-ruler\bookmarklet.txt`

- 用记事本打开（右键 → 打开方式 → 记事本）
- **全选**（`Ctrl+A`）→ **复制**（`Ctrl+C`）
- 看到的内容是 `javascript:` 开头的一大串，很长（约 5700 个字符）——**这是正常的**，它就是整个网格程序本身

> 别删任何字符，也别加换行。

---

## 第 2 步：新建一个书签，把代码粘进去

以 Chrome / Edge 为例：

1. 按 `Ctrl+Shift+B` 打开**书签栏**（浏览器顶部会出现一排书签）
2. 在书签栏**空白处点右键** → 选【添加网页】（有的版本叫【添加书签】）
3. 弹窗里：
   - **名称**：填 `网格`（随便起，这是你自己看的）
   - **网址 / URL**：清空原来的内容，**粘贴**（`Ctrl+V`）刚才复制的那一大串
4. 点【保存】

**如果第 3 步的网址栏不让粘贴**：先随便存一个，然后在书签栏上**右键那个书签 → 修改**，再粘。

## 第 3 步：测试

**测试页**：在文件管理器里打开 `D:\workspace\grid-ruler\test\demo.html`
（右键 → 打开方式 → 选浏览器；或直接把文件拖进浏览器窗口）

页面上有四张卡片，第 1/2/3 张的间距**故意不是 8 的倍数**（13 / 30 / 60），第 4 张是规规矩矩的（16 / 32）。

1. **点一下书签栏上的「网格」** → 应该立刻出现：
   - 满屏 8px 细网格 + 32px 中网格 + 128px 深绿粗网格
   - 顶部和左侧的像素数字（0、128、256…）
   - **右下角一张小面板**（圆角，距边 32px）
2. **对着网格看那四张卡片**：不合规的三张，边框会**落在网格线之间**；合规那张**刚好压在线上**
3. **点小面板上的 `8px` / `32px` / `128px` 色块** → 对应那层网格会单独消失/出现
4. **按住小面板拖动** → 面板会跟着鼠标走，松手记住位置
5. **再点一次书签** → 整个网格消失

全部正常就说明通了。

## 日常怎么用

在**任何网页**上点一下「网格」书签，网格就叠上去；再点一下关掉。
不需要的话，把书签拖到垃圾桶就删掉了，不留任何残留。

**想更快**：在 Chrome 书签管理器里给这个书签设一个「关键字」（比如 `g`），
之后在地址栏输入 `g` 回车就能开关网格，不用去点书签栏。

## 如果没反应，依次检查

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 点了书签跳到搜索页 | URL 没以 `javascript:` 开头（复制时漏了前几个字符） | 重新复制，确认第一个词是 `javascript:` |
| 点了完全没变化 | 部分页面（如 chrome:// 开头的系统页、新标签页）禁止书签运行 | 换一个普通网页再试，比如试验页 |
| 只出现一半就停 | 粘贴时被加了换行或少了字符 | 重新全选复制，别手动编辑 |
| 粘贴时网址栏灰掉不让粘 | 浏览器安全策略 | 先存空书签，再用右键「修改」的方式粘贴 |

## 这是给谁用的

| 对象 | 怎么拿到网格 |
|---|---|
| **你自己（人）** | 这个书签 —— 眼睛看得到，才能说"这里大了一点" |
| **AI** | 技能 `grid-ruler`（不用书签）—— 它拿到的是数字：`24px -> 32px（+8）` |

**两边是同一把尺子**（同一个 `scale.json`），所以你和 AI 说"大一点"时，它算出来的
就是你眼睛看到的那一格。
